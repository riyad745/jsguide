Introduction to JavaScript

JavaScript (JS) is the world's most popular programming language and the only language natively supported by every web browser. It brings websites to life dropdowns, form checks, animations, live data, and full web apps all run on it.

🌐 Frontend

Runs in the browser. Controls buttons, menus, animations, and everything users see and click.

⚙️ Backend (Node.js)

Runs on servers. Powers APIs, authentication, and databases via Node.js.

📱 Mobile & Desktop

Build cross-platform apps with React Native (mobile) and Electron (desktop).

Operators & Expressions

// Arithmetic
10 + 3   // 13
10 % 3   // 1   remainder
2 ** 10  // 1024  exponentiation

// Comparison  ALWAYS prefer === (strict, checks type too)
5 === 5    // true
5 === "5" // false  different types
5 ==  "5" // true   loose, avoid this

// Logical
true && false  // false  AND
true || false  // true   OR
!true          // false  NOT

// Nullish coalescing  default if null/undefined
const user = null ?? "Guest";   // "Guest"

// Optional chaining  safe property access
const city = user?.address?.city; // undefined (no error)

Control Flow

// if / else if / else
const score = 78;
if      (score >= 90) console.log("A");
else if (score >= 80) console.log("B");
else if (score >= 70) console.log("C");  // ← this runs
else                   console.log("F");

// Ternary  one-liner
const result = score >= 60 ? "Pass" : "Fail";

// switch
switch ("Monday") {
  case "Saturday": case "Sunday": console.log("Weekend"); break;
  case "Monday": console.log("Start of week"); break;
  default: console.log("Weekday");
}

Functions

// 1. Function Declaration (hoisted)
function greet(name) { return `Hello, ${name}!`; }

// 2. Arrow Function (modern)
const greet = (name) => `Hello, ${name}!`;
const double = n => n * 2;   // single param, no parens needed

// Default parameters
function createUser(name, role = "viewer") {
  return { name, role };
}
createUser("Alice");        // { name: "Alice", role: "viewer" }

// Rest parameters
const sum = (...nums) => nums.reduce((a, b) => a + b, 0);
sum(1, 2, 3, 4);           // 10

// Closures  a function that remembers its outer scope
function makeCounter() {
  let count = 0;
  return () => ++count;
}
const counter = makeCounter();
counter(); // 1
counter(); // 2
💡 Key Rule: Arrow functions don't have their own this. Use regular functions for object methods.

Arrays

const arr = ["a", "b", "c"];
arr[0];         // "a"
arr.length;    // 3
arr.push("d")  // add to end
arr.pop()      // remove from end
arr.unshift("z") // add to start
arr.shift()    // remove from start
arr.reverse()  // reverse in place

⭐ Functional Methods (Use These Constantly)

const nums = [1, 2, 3, 4, 5];

// map  transform each element → new array
nums.map(n => n * 2);             // [2, 4, 6, 8, 10]

// filter  keep matching elements
nums.filter(n => n > 2);          // [3, 4, 5]

// reduce  collapse to single value
nums.reduce((sum, n) => sum + n, 0); // 15

// find  first match
nums.find(n => n > 3);            // 4

// some / every
nums.some(n => n > 4);            // true (at least one)
nums.every(n => n > 0);           // true (all)

// Chaining
nums.filter(n => n % 2 === 0).map(n => n ** 2); // [4, 16]

// Remove duplicates
[...new Set([1,2,2,3])]; // [1, 2, 3]

DOM Manipulation

The DOM (Document Object Model) is the browser's live tree of your HTML. JavaScript can read and change any part of it. 

// Selecting elements
const btn  = document.querySelector("#submit");    // by ID
const items= document.querySelectorAll(".card");    // all matches
const h1   = document.querySelector("h1");         // by tag

// Reading & writing
h1.textContent = "New Heading";  // plain text (safe)
h1.innerHTML   = "<em>Hello</em>"; // HTML (careful with user input!)

// Styles & classes
h1.style.color = "#f7df1e";
h1.classList.add("highlight");
h1.classList.toggle("active");
h1.classList.contains("highlight"); // true

// Creating & inserting elements
const div = document.createElement("div");
div.textContent = "I'm new!";
document.body.appendChild(div);

Events

const btn = document.querySelector("#btn");

btn.addEventListener("click", (event) => {
  console.log("Clicked!", event.target);
  event.preventDefault(); // stop default behavior
});

// Common events
element.addEventListener("click",     handler);
element.addEventListener("input",     handler); // user typing
element.addEventListener("submit",    handler); // form submit
element.addEventListener("keydown",   handler); // key pressed
element.addEventListener("mouseover", handler); // hover
window.addEventListener("load",       handler); // page loaded

// Event delegation  one listener handles all children
document.querySelector("ul").addEventListener("click", e => {
  if (e.target.matches("li")) console.log(e.target.textContent);
});

Asynchronous JavaScript

JavaScript is single-threaded. Async patterns let it do time-consuming tasks (API calls, timers) without freezing the page. 

// Promises
const p = new Promise((resolve, reject) => {
  setTimeout(() => resolve("Done!"), 1000);
});
p.then(v => console.log(v)).catch(e => console.error(e));

// ⭐ async / await  modern, preferred style
async function getUser(id) {
  try {
    const res  = await fetch(`https://api.example.com/users/${id}`);
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    const user = await res.json();
    return user;
  } catch (err) {
    console.error("Error:", err);
  }
}

// Run multiple requests in parallel
const [posts, users] = await Promise.all([
  fetch("/api/posts").then(r => r.json()),
  fetch("/api/users").then(r => r.json())
]);
ℹ️ How it works: await pauses only the async function not the whole browser. Other code keeps running normally.

ES6+ Modern Features

// Set  unique values
const s = new Set([1,2,2,3]);  // {1, 2, 3}
s.add(4); s.has(2); // true

// Map  key-value with any key type
const m = new Map();
m.set("name", "Alice");
m.get("name");  // "Alice"

// Symbol  guaranteed unique identifier
const id = Symbol("id");

// Generator  pauseable function
function* range(n) {
  for (let i = 0; i < n; i++) yield i;
}
[...range(4)]; // [0, 1, 2, 3]

// Object shorthand
const x = 10, y = 20;
const point = { x, y };        // { x: 10, y: 20 }

// Computed property names
const key = "color";
const obj = { [key]: "red" };  // { color: "red" }

// Array.from
Array.from({ length: 5 }, (_, i) => i + 1); // [1,2,3,4,5]

Object-Oriented Programming

class Animal {
  #name; // private field

  constructor(name, sound) {
    this.#name = name;
    this.sound = sound;
  }

  speak() { return `${this.#name} says ${this.sound}`; }

  static describe() { return "All animals communicate"; }
}

class Dog extends Animal {
  constructor(name) {
    super(name, "Woof");
    this.tricks = [];
  }
  learn(trick) { this.tricks.push(trick); }
  speak() { return super.speak() + " 🐶"; }
}

const rex = new Dog("Rex");
rex.learn("sit");
rex.speak();              // "Rex says Woof 🐶"
rex instanceof Animal;   // true

Error Handling

try {
  const data = JSON.parse("{ bad json");
} catch (err) {
  console.error(err.name);    // "SyntaxError"
  console.error(err.message); // details
} finally {
  console.log("Always runs");
}

// Custom error class
class ValidationError extends Error {
  constructor(message, field) {
    super(message);
    this.name = "ValidationError";
    this.field = field;
  }
}
throw new ValidationError("Invalid age", "age");
⚠️ Never use an empty catch block always log or handle the error. Silent failures are debugging nightmares.

Modules (ES Modules)

// math.js  exporting
export const PI = 3.14159;
export function add(a, b) { return a + b; }
export default function multiply(a, b) { return a * b; }

// main.js  importing
import multiply, { PI, add } from "./math.js";
import * as math from "./math.js";  // import everything

// Dynamic import (load on demand)
const module = await import("./heavy.js");
ℹ️ In HTML: Add type="module" to your script tag: <script type="module" src="main.js"></script>
